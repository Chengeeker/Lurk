# Lurk

An Android reading app built with Kotlin, Jetpack Compose, and Material 3.

- Discussions, replies, search, bookmarks, and browsing history.
- Image galleries and video playback.
- Dark mode, dynamic colors, and font controls.

Android 7.0+ · ARM64
